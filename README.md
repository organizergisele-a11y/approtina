# ROTINA GERAL

Aplicativo instalável (PWA) de rotinas de organização, limpeza e manutenção residencial.
Gisele Oliveira · Personal Organizer de Alto Padrão.

- `dist/` — o aplicativo pronto (HTML, ícones, manifest e service worker). Não há etapa de build.
- `netlify.toml` — diz ao Netlify para publicar a pasta `dist` sem build.
